# Nemo Messenger Global Server

Глобальный сервер для мессенджера Nemo с поддержкой реального времени.

## 🚀 Возможности

- ✅ Реальное время общения через Socket.IO
- ✅ Глобальный поиск пользователей
- ✅ Автоматическая очистка неактивных пользователей
- ✅ Rate limiting для защиты от спама
- ✅ CORS поддержка для всех доменов
- ✅ Статистика и мониторинг
- ✅ Graceful shutdown
- ✅ Обработка ошибок

## 📦 Установка

```bash
npm install
```

## 🔧 Настройка

Скопируйте `.env.example` в `.env` и настройте переменные:

```bash
cp .env.example .env
```

## 🏃‍♂️ Запуск

### Локально
```bash
npm run dev
```

### Продакшн
```bash
npm start
```

## 🌐 Развертывание

### Heroku
1. Создайте приложение на Heroku
2. Подключите GitHub репозиторий
3. Включите автоматическое развертывание
4. Сервер автоматически запустится

### Railway
1. Подключите GitHub репозиторий
2. Railway автоматически определит Node.js проект
3. Сервер запустится автоматически

### Render
1. Создайте новый Web Service
2. Подключите GitHub репозиторий
3. Установите команду сборки: `npm install`
4. Установите команду запуска: `npm start`

## 📊 API Endpoints

- `GET /` - Информация о сервере
- `GET /api/stats` - Статистика сервера
- `GET /api/users` - Список онлайн пользователей
- `GET /api/health` - Проверка здоровья сервера

## 🔌 Socket.IO Events

### Клиент → Сервер
- `user:register` - Регистрация пользователя
- `message:send` - Отправка сообщения
- `user:search` - Поиск пользователя
- `users:get_online` - Получить список онлайн пользователей
- `user:activity` - Обновление активности

### Сервер → Клиент
- `server:info` - Информация о сервере
- `message:new` - Новое сообщение
- `message:delivered` - Подтверждение доставки
- `user:online` - Пользователь в сети
- `user:offline` - Пользователь не в сети
- `users:list` - Список пользователей
- `user:found` - Результат поиска

## 🛡️ Безопасность

- Helmet.js для базовой безопасности
- Rate limiting (1000 запросов за 15 минут)
- CORS настроен для всех доменов
- Автоматическая очистка неактивных пользователей
- Обработка ошибок и graceful shutdown

## 📈 Мониторинг

Сервер предоставляет подробную статистику:
- Количество онлайн пользователей
- Общее количество подключений
- Количество отправленных сообщений
- Время работы сервера
- Использование памяти

## 🔧 Настройка клиента

В вашем мессенджере обновите URL сервера:

```javascript
// В src/services/globalDatabase.ts или cloudSync.ts
const serverUrl = 'https://your-app-name.herokuapp.com';
```

## 📝 Логи

Сервер ведет подробные логи:
- Подключения/отключения пользователей
- Отправка сообщений
- Поиск пользователей
- Ошибки и предупреждения
- Статистика каждые 10 минут

## 🚀 Производительность

- Автоматическая очистка старых сообщений (каждые 6 часов)
- Удаление неактивных пользователей (каждые 2 минуты)
- Оптимизированный поиск через индексы
- Сжатие ответов
- Ограничение размера сообщений (10MB)

## 🆘 Поддержка

Если возникли проблемы:
1. Проверьте логи сервера
2. Убедитесь, что все зависимости установлены
3. Проверьте переменные окружения
