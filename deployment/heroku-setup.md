# 🚀 Развертывание Nemo Messenger на Heroku

## 📋 Что вам понадобится:
- Аккаунт GitHub (бесплатный)
- Аккаунт Heroku (бесплатный)
- 10-15 минут времени

## 🎯 Пошаговая инструкция:

### Шаг 1: Подготовка GitHub репозитория

1. **Создайте новый репозиторий на GitHub:**
   - Зайдите на [github.com](https://github.com)
   - Нажмите "New repository"
   - Назовите его `nemo-messenger-server`
   - Сделайте его публичным
   - Нажмите "Create repository"

2. **Загрузите файлы сервера:**
   ```bash
   # Скачайте все файлы из папки server/
   # Загрузите их в корень вашего GitHub репозитория
   ```

### Шаг 2: Создание приложения на Heroku

1. **Зарегистрируйтесь на Heroku:**
   - Перейдите на [heroku.com](https://heroku.com)
   - Нажмите "Sign up for free"
   - Заполните форму регистрации
   - Подтвердите email

2. **Создайте новое приложение:**
   - В панели Heroku нажмите "New" → "Create new app"
   - Введите уникальное имя (например: `nemo-messenger-2024`)
   - Выберите регион (Europe для лучшей скорости в России)
   - Нажмите "Create app"

### Шаг 3: Подключение GitHub

1. **В разделе "Deploy":**
   - Выберите "GitHub" как deployment method
   - Нажмите "Connect to GitHub"
   - Авторизуйтесь в GitHub
   - Найдите ваш репозиторий `nemo-messenger-server`
   - Нажмите "Connect"

2. **Настройте автоматическое развертывание:**
   - Включите "Automatic deploys"
   - Выберите ветку `main` или `master`
   - Нажмите "Enable Automatic Deploys"

### Шаг 4: Первое развертывание

1. **Запустите развертывание:**
   - В разделе "Manual deploy"
   - Нажмите "Deploy Branch"
   - Дождитесь завершения (2-3 минуты)

2. **Проверьте результат:**
   - Нажмите "View" или "Open app"
   - Вы должны увидеть JSON с информацией о сервере

### Шаг 5: Получение URL сервера

Ваш сервер будет доступен по адресу:
```
https://your-app-name.herokuapp.com
```

Например: `https://nemo-messenger-2024.herokuapp.com`

### Шаг 6: Обновление клиента

Обновите URL в вашем мессенджере:

```javascript
// В src/services/globalDatabase.ts
private databaseUrl = 'https://your-app-name.herokuapp.com';
```

## ✅ Проверка работы

1. **Откройте ваш URL в браузере** - должен показать статистику сервера
2. **Проверьте API endpoints:**
   - `/api/stats` - статистика
   - `/api/users` - список пользователей
   - `/api/health` - проверка здоровья

## 🔧 Настройка переменных окружения (опционально)

В разделе "Settings" → "Config Vars" можете добавить:
- `NODE_ENV` = `production`
- `RATE_LIMIT_MAX_REQUESTS` = `1000`

## 📊 Мониторинг

В панели Heroku вы можете:
- Просматривать логи в реальном времени
- Мониторить использование ресурсов
- Настраивать алерты

## 🚨 Важные моменты

1. **Бесплатный план Heroku:**
   - Приложение "засыпает" после 30 минут неактивности
   - Просыпается при первом запросе (может занять 10-30 секунд)
   - 550 часов в месяц бесплатно

2. **Автоматические обновления:**
   - При каждом push в GitHub сервер автоматически обновляется
   - Процесс занимает 2-3 минуты

3. **Логи и отладка:**
   - Логи доступны в панели Heroku
   - Можно просматривать в реальном времени
