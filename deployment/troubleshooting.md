# 🔧 Решение проблем при развертывании

## ❌ Частые ошибки и их решения

### 1. "Application error" при открытии приложения

**Причина:** Ошибка в коде или отсутствие зависимостей

**Решение:**
1. Проверьте логи в Heroku Dashboard → More → View logs
2. Убедитесь, что файл `package.json` содержит все зависимости
3. Проверьте, что файл `Procfile` существует и содержит: `web: node server.js`

### 2. "Cannot GET /" - пустая страница

**Причина:** Сервер не запустился или неправильный порт

**Решение:**
1. Убедитесь, что в `server.js` используется: `const PORT = process.env.PORT || 3001;`
2. Проверьте логи на наличие ошибок запуска

### 3. "Build failed" при развертывании

**Причина:** Ошибки в package.json или отсутствие файлов

**Решение:**
1. Проверьте синтаксис `package.json`
2. Убедитесь, что все файлы загружены в GitHub
3. Проверьте, что `server.js` находится в корне репозитория

### 4. Сервер работает, но клиент не подключается

**Причина:** Неправильный URL в клиенте или CORS

**Решение:**
1. Обновите URL в клиенте: `https://your-app-name.herokuapp.com`
2. Убедитесь, что CORS настроен на `origin: "*"`
3. Проверьте, что используется HTTPS, а не HTTP

### 5. "Quota exceeded" - превышена квота

**Причина:** Исчерпаны бесплатные часы Heroku

**Решение:**
1. Проверьте использование в Heroku Dashboard
2. Рассмотрите переход на платный план ($7/месяц)
3. Или используйте альтернативные платформы

## 🔍 Отладка

### Просмотр логов в реальном времени:
1. Heroku Dashboard → Your App → More → View logs
2. Или через Heroku CLI: `heroku logs --tail -a your-app-name`

### Проверка статуса приложения:
```bash
curl https://your-app-name.herokuapp.com/api/health
```

### Тестирование подключения:
```javascript
// В консоли браузера
const socket = io('https://your-app-name.herokuapp.com');
socket.on('connect', () => console.log('Подключено!'));
```

## 🆘 Если ничего не помогает

1. **Пересоздайте приложение:**
   - Удалите текущее приложение в Heroku
   - Создайте новое с другим именем
   - Повторите процесс развертывания

2. **Проверьте файлы:**
   - Убедитесь, что все файлы из папки `server/` загружены
   - Проверьте, что нет лишних папок или файлов

3. **Альтернативные платформы:**
   - Railway.app (проще чем Heroku)
   - Render.com (хорошая альтернатива)
   - Vercel (для serverless функций)

## 📞 Поддержка

Если проблема не решается:
1. Скопируйте логи ошибок
2. Опишите что именно не работает
3. Укажите URL вашего приложения
4. Приложите скриншоты если нужно
