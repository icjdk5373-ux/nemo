## 🌐 Получение URL вашего сервера

1. **В панели Railway найдите раздел "Deployments"**
2. **Скопируйте URL вашего сервера**
3. **Он будет выглядеть примерно так:**
   ```
   https://zonal-emotion-production.up.railway.app
   ```

## 🔧 Обновление клиента

Теперь обновите URL в вашем мессенджере:

1. **Откройте файл `src/services/globalDatabase.ts`**
2. **Найдите строку:**
   ```javascript
   private databaseUrl = 'https://nemo-messenger.herokuapp.com';
   ```
3. **Замените на ваш Railway URL:**
   ```javascript
   private databaseUrl = 'https://zonal-emotion-production.up.railway.app';
   ```

## ✅ Проверка работы
