# 🚀 Развертывание Nemo Messenger на Heroku

## 📋 Что у нас есть:
- ✅ GitHub репозиторий: `nemo-messenger-server`
- ✅ Аккаунт на Heroku
- ✅ Все файлы сервера загружены

## 🎯 Пошаговая инструкция:

### Шаг 1: Создание приложения на Heroku

1. **Зайдите в панель Heroku:**
   - Откройте [dashboard.heroku.com](https://dashboard.heroku.com)
   - Войдите в свой аккаунт

2. **Создайте новое приложение:**
   - Нажмите кнопку **"New"** (правый верхний угол)
   - Выберите **"Create new app"**
   
3. **Настройте приложение:**
   - **App name:** `nemo-messenger-global` (или любое уникальное имя)
   - **Region:** `Europe` (для лучшей скорости в России)
   - Нажмите **"Create app"**

### Шаг 2: Подключение GitHub

1. **В разделе "Deploy":**
   - Найдите секцию **"Deployment method"**
   - Нажмите на **"GitHub"**
   
2. **Подключите GitHub:**
   - Нажмите **"Connect to GitHub"**
   - Если нужно, авторизуйтесь в GitHub
   - В поле поиска введите: `nemo-messenger-server`
   - Найдите ваш репозиторий и нажмите **"Connect"**

### Шаг 3: Настройка автоматического развертывания

1. **Включите автоматическое развертывание:**
   - В секции **"Automatic deploys"**
   - Убедитесь, что выбрана ветка **"main"** (или "master")
   - Нажмите **"Enable Automatic Deploys"**

### Шаг 4: Первое развертывание

1. **Запустите развертывание:**
   - В секции **"Manual deploy"**
   - Убедитесь, что выбрана ветка **"main"**
   - Нажмите **"Deploy Branch"**

2. **Дождитесь завершения:**
   - Процесс займет 2-4 минуты
   - Вы увидите логи развертывания в реальном времени
   - В конце должно появиться **"Your app was successfully deployed"**

### Шаг 5: Проверка работы

1. **Откройте приложение:**
   - Нажмите **"View"** или **"Open app"**
   - Или перейдите по URL: `https://your-app-name.herokuapp.com`

2. **Проверьте ответ сервера:**
   Вы должны увидеть JSON примерно такого вида:
   ```json
   {
     "name": "Nemo Messenger Global Server",
     "version": "2.0.0",
     "status": "online",
     "onlineUsers": 0,
     "totalConnections": 0,
     "totalMessages": 0,
     "uptime": "0h 0m 15s"
   }
   ```

### Шаг 6: Получение URL сервера

Ваш сервер теперь доступен по адресу:
```
https://your-app-name.herokuapp.com
```

**Пример:** `https://nemo-messenger-global.herokuapp.com`

### Шаг 7: Обновление клиента

Теперь нужно обновить URL в мессенджере:

1. Откройте файл `src/services/globalDatabase.ts`
2. Найдите строку:
```javascript
private databaseUrl = 'https://nemo-messenger-global-default-rtdb.firebaseio.com';
```
3. Замените на ваш Heroku URL:
```javascript
private databaseUrl = 'https://your-app-name.herokuapp.com';
```

## ✅ Проверка API endpoints

Протестируйте все endpoints:
- `https://your-app-name.herokuapp.com/` - Основная информация
- `https://your-app-name.herokuapp.com/api/stats` - Статистика
- `https://your-app-name.herokuapp.com/api/users` - Список пользователей
- `https://your-app-name.herokuapp.com/api/health` - Проверка здоровья

## 🔧 Настройка переменных окружения (опционально)

1. **В панели Heroku перейдите в "Settings"**
2. **Нажмите "Reveal Config Vars"**
3. **Добавьте переменные:**
   - `NODE_ENV` = `production`
   - `RATE_LIMIT_MAX_REQUESTS` = `1000`

## 📊 Мониторинг

В панели Heroku вы можете:
- **Просматривать логи:** More → View logs
- **Мониторить ресурсы:** Metrics
- **Настраивать алерты:** в разделе настроек

## 🚨 Важные особенности Heroku

### Бесплатный план:
- ✅ 550 часов в месяц бесплатно
- ⚠️ Приложение "засыпает" после 30 минут неактивности
- ⚠️ Просыпается при первом запросе (10-30 секунд)
- ✅ Автоматические обновления при push в GitHub

### Для продакшена:
- Рассмотрите платный план ($7/месяц) для постоянной работы
- Или используйте альтернативы: Railway, Render

## 🔄 Автоматические обновления

При каждом изменении в GitHub репозитории:
1. Heroku автоматически скачает изменения
2. Пересоберет приложение
3. Перезапустит сервер
4. Процесс займет 2-3 минуты

## 🆘 Если что-то пошло не так

### Проблема: "Application error"
**Решение:** Проверьте логи в More → View logs

### Проблема: "Build failed"
**Решение:** Убедитесь, что все файлы загружены в GitHub

### Проблема: Сервер не отвечает
**Решение:** Подождите 30 секунд (приложение просыпается)

### Проблема: Клиент не подключается
**Решение:** Проверьте URL в `globalDatabase.ts`
