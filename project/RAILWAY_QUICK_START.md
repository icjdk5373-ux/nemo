# 🚄 Railway - Быстрый старт (5 минут)

## ⚡ Самый простой способ:

### Шаг 1: Переход на Railway
1. **Откройте новую вкладку:** [railway.app](https://railway.app)
2. **Нажмите "Start a New Project"**

### Шаг 2: Авторизация
1. **Нажмите "Login with GitHub"**
2. **Разрешите доступ Railway к GitHub**

### Шаг 3: Развертывание
1. **Нажмите "Deploy from GitHub repo"**
2. **Найдите любой репозиторий (можно создать пустой)**
3. **Или нажмите "Deploy from template"**

### Шаг 4: Загрузка файлов
1. **После создания проекта загрузите файлы сервера**
2. **Railway автоматически определит Node.js проект**
3. **Развертывание начнется автоматически**

## ✅ Преимущества Railway:
- 🆓 **Полностью бесплатно**
- 🚫 **Не требует карту**
- ⚡ **Не засыпает приложение**
- 🔄 **Автоматические обновления**
- 🌍 **Глобальный доступ**

## 🎯 Результат:
Получите URL вида: `https://your-project.up.railway.app`
