# 🚀 Развертывание Nemo Messenger на Heroku - Пошаговая инструкция

## 🎯 Что нужно сделать сейчас:

### Шаг 1: Создание нового приложения

1. **На главной странице Heroku нажмите "Create new app"**
   - Это большая кнопка в центре или в меню "New"

2. **Заполните форму:**
   - **App name:** `nemo-messenger-2024` (или любое уникальное имя)
   - **Region:** `Europe` (для лучшей скорости)
   - Нажмите **"Create app"**

### Шаг 2: Подключение GitHub репозитория

1. **В разделе "Deploy" найдите "Deployment method"**
2. **Нажмите на иконку "GitHub"**
3. **Нажмите "Connect to GitHub"** (если еще не подключен)
4. **В поле поиска введите:** `nemo-messenger-server`
5. **Найдите ваш репозиторий и нажмите "Connect"**

### Шаг 3: Настройка автоматического развертывания

1. **В секции "Automatic deploys":**
   - Убедитесь, что выбрана ветка `main`
   - Нажмите **"Enable Automatic Deploys"**

### Шаг 4: Первое развертывание

1. **В секции "Manual deploy":**
   - Выберите ветку `main`
   - Нажмите **"Deploy Branch"**

2. **Дождитесь завершения (2-3 минуты)**
   - Вы увидите логи развертывания
   - В конце должно появиться "Your app was successfully deployed"

### Шаг 5: Проверка работы

1. **Нажмите "View" или "Open app"**
2. **Вы должны увидеть JSON с информацией о сервере:**

```json
{
  "name": "Nemo Messenger Global Server",
  "version": "2.0.0",
  "status": "online",
  "onlineUsers": 0,
  "totalConnections": 0,
  "totalMessages": 0
}
```

## ✅ Ваш сервер будет доступен по адресу:
```
https://your-app-name.herokuapp.com
```

## 🔧 Обновление клиента

После получения URL обновите его в мессенджере:

1. Откройте `src/services/globalDatabase.ts`
2. Замените URL:
```javascript
private databaseUrl = 'https://your-app-name.herokuapp.com';
```

## 🎉 Готово!

После этого все пользователи мессенджера смогут общаться через ваш глобальный сервер!

## 🆘 Если возникли проблемы:

### "Application error"
- Проверьте логи: More → View logs
- Убедитесь, что все файлы загружены в GitHub

### "Build failed"
- Проверьте, что `package.json` и `server.js` в корне репозитория
- Убедитесь, что нет ошибок в коде

### Сервер не отвечает
- Подождите 30 секунд (приложение может "просыпаться")
- Попробуйте обновить страницу
