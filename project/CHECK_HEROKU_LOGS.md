# 🔍 Проверка логов Heroku приложения

## 📊 Команды для проверки

### 1. Проверьте логи приложения:
```cmd
heroku logs --tail -a nemo-messenger-server
```

### 2. Если не знаете точное имя приложения:
```cmd
heroku apps
```

### 3. Проверьте статус приложения:
```cmd
heroku ps -a nemo-messenger-server
```

### 4. Проверьте переменные окружения:
```cmd
heroku config -a nemo-messenger-server
```

## 🎯 Что искать в логах:

### ✅ Успешный запуск выглядит так:
```
2024-01-15T10:30:15.123456+00:00 app[web.1]: 🚀 Nemo Messenger Global Server запущен на порту 12345
2024-01-15T10:30:15.123456+00:00 app[web.1]: 🌐 Сервер доступен для всех пользователей мира
```

### ❌ Ошибки могут выглядеть так:
```
2024-01-15T10:30:15.123456+00:00 app[web.1]: Error: Cannot find module 'express'
2024-01-15T10:30:15.123456+00:00 app[web.1]: npm ERR! missing script: start
2024-01-15T10:30:15.123456+00:00 app[web.1]: Error: listen EADDRINUSE
```

## 🔧 Частые проблемы и решения:

### Проблема 1: "Cannot find module"
**Решение:** Проблема с package.json
```cmd
# Проверьте содержимое package.json в GitHub
# Убедитесь, что все зависимости указаны
```

### Проблема 2: "missing script: start"
**Решение:** Добавьте в package.json:
```json
{
  "scripts": {
    "start": "node server.js"
  }
}
```

### Проблема 3: "Error: listen EADDRINUSE"
**Решение:** Проблема с портом в server.js:
```javascript
const PORT = process.env.PORT || 3001;
```

### Проблема 4: "Application error"
**Решение:** Проверьте, что файл server.js существует и корректен

## 📝 Следующие шаги:

2. **Скопируйте вывод логов**
3. **Найдите ошибки (строки с "Error" или "ERR")**
4. **Сообщите какие ошибки видите**

## 🆘 Если логи показывают ошибки:

Скопируйте и пришлите:
- Полный вывод команды `heroku logs --tail -a your-app-name`
- Особенно строки с ошибками
- URL вашего GitHub репозитория

## ⚡ Быстрая диагностика:

### Проверьте URL приложения в браузере:
```
https://your-app-name.herokuapp.com
```
